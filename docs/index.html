Search

The Search Workflow

Type a question in plain English. Here's how you get your answer.

"What authentication bugs were fixed recently?"
↓
Your Question → Embedding
Same AI model converts your question into a meaning fingerprint
↓
Cosine Similarity Search
Finds the closest matching chunks by comparing fingerprints — runs in milliseconds
↓
Ranked Results
Results sorted by relevance, each showing the source, a snippet, and a similarity score

Why is this different from regular keyword search?

  • ✓
    Understands meaning, not just words. Search for "login problems" and find documents about "authentication errors" — even if those exact words aren't used.
  • ✓
    Works across all your data. One search query spans GitHub issues, emails, PDFs, and notes simultaneously.
  • ✓
    Completely private. Everything runs on your machine. No data ever leaves your computer.

Smart Features

Built to Be Efficient

No wasted work. The system is designed to be smart about what it processes.

Content Deduplication

Every document is fingerprinted with SHA-256. If it hasn't changed since last sync, it's skipped entirely — no re-embedding needed.

Incremental Sync

Only new or changed content gets processed when you re-sync a source. Saves time and computing power.

Runs 100% Locally

No cloud services, no API keys required, no data leaving your machine. Everything runs in Docker on your own computer.

Getting Started

Up and Running in Minutes

Two ways to run — pick whichever suits you.

Option A: Docker (Easiest)

Everything in containers. Just need Docker installed.

  1. Clone and configure

    cp .env.example .env

  2. Start all services

    make docker-up

  3. Run database migrations

    docker compose exec backend alembic upgrade head

  4. Open the app

    Visit http://localhost:3000 in your browser.

Option B: Local Development

Infrastructure in Docker, code running locally with hot-reload.

  1. Start infrastructure

    docker compose up -d postgres redis

  2. Start the backend

    cd backend python -m venv .venv source .venv/bin/activate pip install -r requirements-dev.txt alembic upgrade head uvicorn app.main:app --reload --port 8000

  3. Start the frontend

    cd frontend npm install npm run dev

  4. Open the app

    Visit http://localhost:3000 in your browser.
